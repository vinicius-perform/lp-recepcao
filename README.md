# Kit Recepção que Vende — Edição HOF & Estética

Landing page de vendas de alta conversão para o produto digital **Kit Recepção que Vende | Edição HOF**, comercializado por **R$ 19,90** (pagamento único).

Projetada com direção visual *The Golden Edition* (estética champagne, silent luxury, editorial contemporâneo) e copy de resposta direta sem chavões de infoproduto barato.

## 💎 Diferenciais do Produto
- **120 scripts comerciais prontos** para WhatsApp.
- **3 packs organizados**:
  - **Pack 01 — Respostas que Agendam** (45 scripts: primeiro contato, valores de Botox/preenchimento, objeções e follow-up).
  - **Pack 02 — Agenda Protegida** (35 scripts: confirmações, lembretes, reagendamentos e no-shows).
  - **Pack 03 — Pacientes de Volta** (40 scripts: recall de 15 dias, avaliações antigas, pós e bioestimuladores).
- **Execução imediata**: *Abriu → Encontrou → Copiou → Enviou*.

## ⚡ Fluxo de Compra e CRO
- Formulário enxuto de 4 campos (Nome, WhatsApp, E-mail, Instagram).
- **Popup de Checkout Imediato**: ao enviar o formulário, o popup abre com os dados do comprador já pré-preenchidos.
- Suporte a **Pix Instantâneo** com QR Code e Pix Copia e Cola + **Cartão de Crédito**.
- Disparo de eventos de conversão e deduplicação de `Purchase` por `event_id`.
- Liberação segura de acesso via link individualizado.

## 🛠️ Tecnologias
- **React 18** + **TypeScript**
- **Tailwind CSS** com tipografia editorial (*Manrope* + *Cormorant Garamond*)
- **Vite 6**
- **Lucide React**

## 🚀 Como Executar

```bash
# Instalar dependências (caso não estejam instaladas)
bun install # ou npm install

# Iniciar servidor local com Hot Reload
bun run dev

# Build de produção
bun run build

# Preview da build de produção
bun run preview
```
